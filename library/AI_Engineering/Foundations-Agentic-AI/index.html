Foundations of Agentic AI

How language models became agents that reason, use tools, remember, plan, cooperate and learn from their own experience, and how to make such agents reliable, affordable and safe. Written for mathematicians and data scientists preparing for AI-lab and FAANG interviews.

Who this book is for

You are comfortable with linear algebra, probability, optimisation and Python, and you have trained models as a data scientist, but you have not built software systems that act in the world: you have not written a tool interface, sandboxed untrusted code, designed a retrieval index or trained a policy with reinforcement learning. This book gives you that understanding in the mathematical language you already speak. An agent is treated as a policy acting in a partially observed decision process, and every technique (chain of thought, tool calling, retrieval, memory, multi-agent orchestration, reinforcement learning from verifiable rewards) is derived from the problem it solves. "For the mathematician" boxes translate software concepts into mathematics. Three running examples recur throughout: a coding agent that fixes a GitHub issue, an airline support agent bound by a policy, and a research agent that writes a cited report.

How each chapter works

  • Theory told as an evolution: problem → idea → new bottleneck, with dates and the people who did it.
  • Worked examples and drills that put numbers on reliability, cost and latency.
  • MCQs with explanations, and interview questions graded Warm-up / Core / Deep-dive / Design.
  • References to primary sources at the end of every chapter.
