Introduction to LLM Engineering

Inference, serving and systems for large language models—from Shannon's n-grams to Blackwell GPUs—written for mathematicians and data scientists preparing for FAANG-level ML-systems interviews.

Every chapter tells the story of a bottleneck and the ideas that broke it, with rigorous derivations, hand-drawn SVG diagrams, KaTeX equations, interactive multiple-choice questions and graded interview questions. Who this book is for

You are comfortable with linear algebra, probability, optimisation and Python, and you have trained models as a data scientist—but you have not written CUDA, thought about memory hierarchies, or designed a distributed system. This book gives you the machine-level and systems-level understanding that inference-engineering interviews probe, using the mathematical language you already speak. "For the mathematician" boxes translate systems concepts into mathematics. Three running examples (Llama 3 8B, Llama 3 70B and DeepSeek-V3 on an H100) recur throughout, so the numbers build on each other from chapter to chapter.

How each chapter works

  • Theory told as an evolution: problem → idea → new bottleneck.
  • Worked examples and drills with real model configs (Llama, Mistral, DeepSeek) and real hardware (A100, H100, H200, B200).
  • MCQs with explanations, and interview questions graded Warm-up / Core / Deep-dive / Design.
  • References to primary sources at the end of every chapter.
